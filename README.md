# Game Hub (JS Games Collection)

## Description
Game Hub is an interactive platform featuring multiple mini-games built entirely with vanilla JavaScript. Unlike a single-page setup, each game now has its own dedicated page, providing a smoother and more engaging user experience. Users can play games like Snake, Tic Tac Toe, Memory Card Flip, Dice Roller, Wordle, and Sudoku. The project demonstrates extensive use of JavaScript concepts including DOM manipulation, events, OOP, arrays, timers, localStorage, and page navigation.

## Features
- **Dedicated Game Pages:** Each game has a separate, responsive page for better user experience.
- **Snake Game:** Move the snake with arrow keys, eat food, grow in size, and track your score.
- **Tic Tac Toe:** 2-player game with win detection, reset, and interactive UI.
- **Memory Card Flip:** Match pairs of cards with move tracking, timer, and animated card flips.
- **Dice Roller:** Roll dice with dynamic results and animations.
- **Wordle & Sudoku:** Puzzle games with validations, hints, and interactive gameplay.
- **Leaderboard:** Save high scores in localStorage.
- **Dark Mode:** Toggle between light and dark themes across all pages.
- **Responsive Design:** Works seamlessly on desktops, tablets, and mobile devices.
- **Interactive UI:** Buttons, hover effects, and game transitions enhance engagement.

## Tech Stack
- HTML, CSS, JavaScript (ES6+)
- Browser APIs: Canvas, localStorage, timers, events
- Modular JavaScript with classes and reusable functions

## How to Run & Learning Outcomes
Open `index.html` in a web browser, then click on any game to navigate to its dedicated page and start playing.  
**Learning Outcomes:** DOM manipulation and event handling, OOP and modular JavaScript, timers and asynchronous behavior, array and string operations, LocalStorage for persistence, Canvas API for game graphics, building interactive multi-page applications.
