Welcome to Game Hub 🎲

Game Hub is a collection of fun mini-games built entirely with HTML, CSS, and Vanilla JavaScript.

Explore classic and modern games including Snake, Tic Tac Toe, Memory Card Flip, Dice Roller, and Wordle. Each game is lightweight, interactive, and demonstrates different JavaScript concepts like DOM manipulation, Canvas API, events, and localStorage.

✨ Features

  • Snake Game – eat, grow, and chase high scores
  • Tic Tac Toe – play against a friend locally
  • Memory Card Flip – match pairs under time pressure
  • Dice Roller – random fun with dice
  • Wordle – guess the secret word
  • Dark Mode & Leaderboard – save scores and toggle themes
